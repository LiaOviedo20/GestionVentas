# Sistema de Gestión de Eventos y Venta de Entradas

## Descripción del Proyecto

Este proyecto consiste en una aplicación web desarrollada con Node.js, Express, MySQL y EJS para la gestión de eventos y venta de entradas.

El sistema permite crear, visualizar y eliminar eventos mediante una API REST conectada a una base de datos MySQL. Además, incluye un sistema anti-reventa que limita la cantidad de entradas que un usuario puede comprar para evitar compras masivas y reventas a precios elevados.

La aplicación cuenta con frontend y backend separados, siguiendo una arquitectura moderna y utilizando Bootstrap para el diseño visual de la interfaz.
